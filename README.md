# wezterm-config

My [WezTerm](https://wezterm.org) terminal config.

## Highlights

- JetBrains Mono, 16pt
- Cyberpunk color scheme with matching neon tab bar
- 40% window opacity with macOS background blur
- Integrated title bar buttons

## Install

```sh
git clone https://github.com/nathandalpatan/wezterm-config ~/.config/wezterm
```

WezTerm picks up `~/.config/wezterm/wezterm.lua` automatically.
